# 模型遥测模块就绪审查

## 结论

**CONDITIONAL GO**：适合本地作品演示和面试讲解；不应把当前内存窗口描述为公网生产监控。审查置信度为 **Medium**，代码、测试和本地容器运行已经验证，但持久化监控、告警与多实例聚合尚未接入。

## 范围与核心流程

- 发布目标：本地作品演示。
- 项目形态：带账户、数据库、外部本地模型依赖和浏览器界面的 FastAPI 服务。
- 核心流程：登录用户发起站内流式问答，看到最终答案和引用；系统产生不含正文的遥测事件，管理员可以查看聚合结果。
- 关键不变量：Prompt、回答、用户 ID 和上游错误正文不得进入遥测；普通用户不得查看聚合接口；内存使用必须有界。

## 能力与证据

| 检查项 | 状态 | 证据与边界 |
| --- | --- | --- |
| AI / 外部模型 | Verified | 真实 Ollama 流式请求成功，事件包含 operation、provider、model、outcome、latency 和 TTFT。 |
| 隐私最小化 | Verified | 事件结构无正文和用户标识；单元测试检查隐私声明与输出字段。 |
| 认证与角色 | Verified | 路由声明 `require_admin`，未登录运行态请求返回 401，普通角色路径由既有依赖测试覆盖。 |
| 容量上界 | Verified | 单进程窗口固定保留最近 200 条，覆盖测试证明旧事件会淘汰。 |
| 失败可诊断性 | Verified | 安全失败分类覆盖 timeout、upstream、configuration、application 和 internal。 |
| 持久化与多实例聚合 | Missing (P1 for public launch) | 进程重启会清空聚合结果，各实例窗口彼此独立。 |
| 告警、负责人和运行手册 | Missing (P1 for public launch) | 当前没有错误率、P95 延迟或模型容量告警。 |
| token / 成本 | Not verified | 当前本地提供方没有稳定用量字段；本模块不生成推测数字。 |

## 风险与后续验证

公网发布前应将 `llm_telemetry` JSON 日志导出到持久化平台，验证跨实例聚合、保留期和访问权限，并为错误率、P95 延迟、容量和成本设置有负责人且经过演练的告警。完成标准是一次受控模型故障能触发告警，并可从日志定位 provider、operation、失败类别和发布版本，而无需查看用户正文。
