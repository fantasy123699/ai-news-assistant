# -
新闻模块：负责新闻分类、新闻列表、新闻详情、相关推荐和新闻增删改查。 用户模块：负责注册、登录、退出、用户信息获取和修改。 收藏模块：负责添加收藏、取消收藏、收藏列表和清空收藏。 历史模块：负责记录浏览历史、查看历史、删除历史和清空历史。 AI 模块：负责新闻总结、新闻问答、站内新闻库聊天和 AI 聊天记录查询。

## Docker 快速启动

安装 Docker Desktop 后，在项目根目录运行：

```bash
docker compose up --build
```

然后访问 `http://localhost:8000`，健康检查地址为 `http://localhost:8000/health`。MySQL 会在首次创建数据卷时自动执行数据库结构和示例数据脚本。

AI 接口默认连接宿主机的 `http://localhost:11435`；其他端口、停止方式、数据重置和生产注意事项见 [容器运行说明](docs/container-run.md)。
